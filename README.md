\# EagleApps Grading Dashboard



\*\*Version:\*\* 1.0 MVP  

\*\*Status:\*\* Internal prototype  

\*\*Platform:\*\* Windows  

\*\*Environments:\*\* QA and PROD



\## Overview



The EagleApps Grading Dashboard is a local internal application that provides

a consolidated view of grading activity and selected roster data-quality

issues.



The application connects directly to Oracle using the credentials entered by

the user at sign-in. Oracle passwords are retained only in the local server

process for the active session and are not stored in environment files,

browser cookies, application logs, or application source code.



\## Current MVP capabilities



\- Oracle credential authentication

\- Separate QA and PROD configurations

\- One-click Windows launchers

\- Term selection

\- Grading-status summaries

\- Instructor names and email information

\- Duplicate roster detection

\- Duplicate student-row detection

\- Withdrawal-and-grade conflict detection

\- Client-side search, filtering, and sorting

\- CSV export

\- Environment identification within the application
